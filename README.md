# Skystore

Интернет-магазин. 

## Технологии

- Python 3.13
- Django
- Bootstrap 5
- Poetry

## Установка и запуск

1. Клонировать репозиторий
2. Установить Poetry: https://python-poetry.org/docs/
3. Установить зависимости:
poetry install  
4. Активировать виртуальное окружение: poetry shell  
5. Запустить сервер: python manage.py runserver  


## Структура проекта

- `catalog` — приложение с основным функционалом
- `templates/catalog` — HTML-шаблоны
